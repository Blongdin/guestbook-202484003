# 03: 비밀번호 확인 후 메시지 수정 (Update)

**What to build:** 각 방명록 글의 [수정] 버튼을 누르면 기존 메시지가 채워진 수정 폼이 그 글 아래에 펼쳐진다. 작성자가 새 메시지와 맞는 비밀번호를 입력하면 메시지가 바뀌고 "(수정됨)" 표시가 붙으며, 목록에서의 위치(작성 시각 기준)는 그대로다. 비밀번호가 틀리면 수정이 거부되고 폼 안에 "비밀번호가 일치하지 않습니다."가 표시되며, 입력한 새 메시지는 유지된다. 이름은 수정할 수 없다. 수정·삭제 인라인 폼은 한 번에 하나만 열린다. 세부 계약은 `.scratch/guestbook/spec.md`를 따른다.

**Blocked by:** 01 (방명록 글 작성과 목록 조회), 02 (비밀번호 확인 후 삭제)

**Status:** ready-for-agent

- [ ] `PATCH /api/entries/[id]`는 `{ message, password }`를 받아, 맞으면 `200`과 수정된 방명록 글(`updatedAt` 값 있음), 틀리면 `403`, 글이 없으면 `404`, 메시지 검증 실패(trim 후 1–500자 위반) 또는 비밀번호 누락이면 `400`을 돌려준다
- [ ] 수정은 메시지와 `updated_at`만 바꾸고, 이름과 `created_at`은 바꾸지 않는다
- [ ] 수정 후에도 목록 정렬 위치가 바뀌지 않는다
- [ ] `updatedAt`에 값이 있는 방명록 글에는 "(수정됨)"이 작게 표시된다
- [ ] [수정]을 누르면 기존 메시지가 채워진 textarea, 비밀번호 입력, [저장] [취소]가 있는 인라인 폼이 열린다
- [ ] `403`이면 폼 안에 빨간 글씨로 안내가 표시되고, 입력한 메시지는 유지되며 비밀번호 칸만 비워진다
- [ ] `404`이면 안내가 표시되고 목록이 갱신된다
- [ ] 성공하면 폼이 닫히고 목록에 새 메시지가 반영된다
- [ ] 수정 폼과 삭제 폼을 통틀어 한 번에 하나만 열리고, 다른 글의 폼을 열면 이전 폼이 닫힌다
- [ ] `npm run smoke`가 스펙의 smoke 1–8단계를 모두 통과한다(틀린 비밀번호 `PATCH` → `403` 후 메시지 변경 없음, 맞는 비밀번호 → `200`, 메시지 변경, `updatedAt` 있음)
- [ ] `npm run build`가 통과한다
